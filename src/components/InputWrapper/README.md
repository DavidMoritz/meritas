# InputWrapper

## Usage

```tsx
<InputWrapper
  id={"input-id"}
  label={"input-label"}
  srOnlyLabel={false}
  required={true}
  moreInfo={"More info tooltip."}
  footnote={"footnote string"}
  invalid={false}
  invalidMessage={"This input is invalid"}
>
    <!-- Input goes here -->
</InputWrapper>
```
